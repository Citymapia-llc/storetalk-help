---
title: "Importing contacts from Excel or CSV"
description: "Bulk upload your existing customer list in two easy steps."
---

Already have a customer list in Excel or Google Sheets? You can import it into StoreTalk in minutes. No technical knowledge needed.

## Prepare your spreadsheet

Your spreadsheet needs at minimum a **Phone** column. Other columns are optional but recommended.

| Column | Example | Required? |
|--------|---------|-----------|
| Phone  | +91 98765 43210 | Yes |
| Name   | Rahul Sharma | Optional |
| Email  | rahul@example.com | Optional |
| Tags   | VIP, Mumbai | Optional |

<Tip>
  Include the country code with every number: **+91 98765 43210**, not 98765 43210. Spaces, dashes and brackets are fine, and StoreTalk removes them automatically. A number that starts with **00** instead of **+** (for example 0091 98765 43210) also works.
</Tip>

<Note>
  Why the country code? StoreTalk works with customers in many countries, and a number without one is ambiguous. For example, **6591234567** is a valid Singapore number and could also be mistaken for an Indian one. StoreTalk doesn't guess, so the message always reaches the right person.
</Note>

## How to import

<Steps>
  <Step title="Go to Contacts">
    Click **Contacts** in the left menu.
  </Step>
  <Step title="Click Import">
    Click the **Import** button in the top-right corner.
  </Step>
  <Step title="Upload your file">
    Upload your `.csv` or `.xlsx` file.
  </Step>
  <Step title="Map your columns">
    Match your spreadsheet columns to the Contact fields — for example, column A → Phone.
  </Step>
  <Step title="Choose what to do with numbers that have no country code">
    Under **Numbers without a country code**, pick one:
    - **Skip them (report as errors)** — the default. Those rows are not imported and are listed in the results so you can fix them.
    - **Treat as +91 (IN)** (or another country): use this only if *every* local number in the file is from that country. Numbers that already start with + or 00 are kept as they are.
  </Step>
  <Step title="Import">
    Click **Import**. StoreTalk imports all rows and skips duplicates automatically.
  </Step>
</Steps>

<Warning>
  If a phone number already exists as a contact, the import will update their name and tags — it will not create a duplicate.
</Warning>

## If some rows show errors

After the import, StoreTalk lists any rows it skipped and why. The most common reason is:

> **Phone number must include the country code, e.g. +91 98765 43210**

Add the country code to those numbers in your spreadsheet and import the file again. Rows that were already imported are updated, not duplicated. Alternatively, run the import again and choose the right country under **Numbers without a country code**.

## After import

Imported contacts appear immediately in your Contacts list. You can now add them to Segments and target them with Campaigns.
